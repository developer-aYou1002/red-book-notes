## 发布正文 V1

Windows 快捷键不用一次全背下来，先收藏一张按场景分类的速查表，需要时再回来找。

这次整理了 78 组工作中常见的组合键，分成编辑与保存、文字选择、窗口排列、系统入口、截图与剪贴板、文件管理、浏览器标签页、虚拟桌面与任务栏 8 类。最后一页只挑 12 组最高频的，先记它们就够了。

这份清单按 Windows 11 默认行为整理。不同应用可能改写部分组合键，例如 `Ctrl+Shift+V` 并不是处处都支持；`PrtScn` 的行为可以在设置里修改；`Win+V` 的剪贴板历史默认可能还没开启。浏览器页以 Windows 版 Microsoft Edge 为准，其他浏览器大多相近，但仍以实际版本为准。

另外，`Shift+Delete` 不经过回收站，重要文件不要随便试。
