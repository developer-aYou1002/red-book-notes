- [微软支持：使用截图工具捕获截图](https://support.microsoft.com/zh-cn/windows/apps/use-snipping-tool-to-capture-screenshots)。
- 页面标题：使用截图工具捕获截图；域名：`support.microsoft.com`。
- 页面显示适用对象：Windows 11、Windows 10。核对内容取 Windows 11 段落。
- 页面未显示发布日期／更新日期；访问日期：2026-09-16。不可把访问日期写成发布日期。
- 对应原文位置：“打开截图工具”说明 Windows 徽标键 + Shift + S 打开截图工具覆盖层；“捕获截图”说明选择截图模式、区域；“保存截图”说明捕获后默认保存到“屏幕截图”文件夹，并可在设置中更改自动保存行为或默认文件夹。
- 核对结论：快捷键只是打开截图覆盖层，仍需选取区域；默认自动保存的说法来自微软当前 Windows 11 页面，但存在设置可更改的条件。
