## 发布正文（可直接复制）

新手提问时，可以先检查这 4 项：
任务、背景、要求、输出格式。

如果需要特定的专业视角，再补充角色。它不是必须写满的固定公式，关键是把真正影响结果的条件说清楚。

第 4 页用一个匿名模拟案例，展示怎样把零散工作记录整理成周报；SQL 则是学习场景示例，换成其他陌生概念也能套用。

下面这段可以直接复制，把【】里的内容换成自己的：

请帮我完成【任务】。
背景：【已有资料、给谁看、使用场景】。
要求：
1.【要求1】
2.【要求2】
3.【限制或不能编造的内容】
请按【输出格式】输出。
如果缺少会影响结果的关键信息，请先问我；其他不确定之处标为“待确认”，不要直接猜测。

如果需要特定视角，还可以补一句：
请从【角色】的视角回答。

使用工作资料前，记得删除姓名、客户信息和未公开内容。生成后，也要自己核对事实、数字和表达。

## 完整示例①：上班族写周报

普通问法：帮我写一份周报。

图片中的匿名模拟材料：本周整理了 3 条用户反馈，完成首页按钮文案调整；搜索结果页尚未联调。下周计划：确认搜索结果页的联调时间。未提供真实姓名、客户资料或未公开信息。图片中的周报结果为编辑示意，并非 ChatGPT 实测。

升级问法（替换工作内容后再用）：

你是一名擅长整理工作汇报的助手。
请根据我提供的工作记录，整理一份给直属领导看的周报。
要求：语言简洁专业；不写流水账；区分已完成成果、问题与风险、下周计划；原文没有的进度、数字和风险不要编造，不明确之处标“待确认”。
格式：一、本周完成事项；二、关键成果；三、问题与风险；四、下周计划。
我的工作记录：【粘贴真实内容，提交前去掉敏感信息】

## 完整示例②：学习 SQL

普通问法：给我讲一下 SQL。

升级问法：

请像给零基础学生讲课一样解释 SQL。我没有数据库基础，希望先理解它是什么、能做什么，以及最常见的查询思路。
要求：少用术语；每个关键概念给一个生活化例子；先讲入门最重要的内容；最后出 3 道简单练习题，暂时不要公布答案。等我回答后，再给提示和反馈。
格式：一句话解释 → 生活例子 → 三个入门重点 → 三道练习题。

## 完整示例③：做小红书图文

普通问法：帮我写一篇小红书。

升级问法：

请帮我设计一篇 7 页小红书图文笔记。账号定位：AI、软件、电脑效率；目标读者：18～35 岁的学生、上班族和经常用电脑的人。主题：《ChatGPT新手最值得学的5种用法》。
要求：语气口语化，不写得像广告；开头直接点出用户痛点；每页只讲一个重点；最后一页给明确收藏理由。标题与事实不要夸大，没有提供的实测数据不要编造。
请输出：封面标题 → 每页文案 → 笔记标题 → 正文 → 标签。
