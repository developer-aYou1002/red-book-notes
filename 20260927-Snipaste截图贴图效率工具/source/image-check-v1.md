# Snipaste V1 图片 QA

检查日期：2026-09-27  
检查对象：`images-v1/` 与 `preview-v1/`

## 文件与尺寸

- 8 张 V1 原图均为 1200×1600 PNG。
- 8 张手机预览均为 360×480 PNG。
- `preview-v1/contact-sheet.png` 已生成，用于统一检查版式与顺序。
- 顺序：封面 → 痛点 → 基础流程 → 文档场景 → 表格场景 → 3 个补充用法 → 版本授权 → 收藏总结。

## 手机宽度检查

- 8 页主标题在 360px 预览中均可识别。
- 第 3 页 F1／F3 键帽与四步流程清晰，没有用小字承载核心步骤。
- 第 4、5 页的贴图卡和工作窗口关系清楚，均标注“场景演示｜虚构材料”。
- 第 6 页显著标注“官网功能说明”，没有伪装成 A 的亲测结果。
- 第 7 页能区分免费基础能力、专业版代表能力和商业授权边界。
- 底部品牌、页码与说明均在安全区内，无裁切。

## 视觉检查

- 使用暖白／浅灰桌面背景与绿色、青色动作色，不沿用第 7 篇深色速查表。
- 封面先突出“截图还能钉在屏幕上”，Snipaste 名称作为工具识别而非广告主视觉。
- 视觉中的窗口与资料卡均为编辑示意，不使用官网宣传图或伪造软件界面截图。
- 所有案例信息均来自统一的虚构“秋季阅读活动”材料。

## 风险检查

- 未出现“神器、必装、最好用、效率翻倍、完全免费”等无依据表达。
- 未把专业版能力写成免费基础功能。
- 未把个人非商业免费扩大到公司／商业场景。
- 正文保留隐私提醒、后台运行、快捷键可调整与贴图过多会遮挡的边界。

结论：V1 图片包可提交 B 首次评审，不代表可发布。
