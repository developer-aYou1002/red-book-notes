ChatGPT新手最值得学的5种用法

## 发布正文

上一篇讲了普通人先认识哪5款AI工具，这篇先从最常用的 ChatGPT 开始。

新手不用先背一长串提示词。拿一个手头的真实任务，给它背景和材料，让它先做一版，再由自己核对、修改，通常更容易上手。

新手可以先从这5类任务练习：

1️⃣ 写作润色：把自己写的周报改清楚，不让它编造进度。
2️⃣ 总结提炼：把零散会议记录变成重点和待办，推导出的动作要标“建议跟进”，负责人、时间仍要核对。
3️⃣ 学习讲解：用生活里的例子理解概念，再让它反问自己是否真的懂了。
4️⃣ 分析拆解：没有数据值时，先搭“曝光→点击率→报名转化率”的分析路径，不把检查框架说成分析结论。
5️⃣ 方案规划：告诉它目标、时间和限制，让每一步都有可检查的成果，再修改计划初稿。

每页都有一个“输入前／输出后”示意和一句可以直接改着用的提问。示例结果是演示写法，不是我在 ChatGPT 中完成的实测，也不代表 ChatGPT 一定会给出同样答案；涉及事实、数字、责任人或重要决策，请回到原始资料核对。

记住这个顺序：先给背景 → 说清目标 → 指定格式 → 自己核对结果。

## 完整版示例提问

图片只放两行短提问，下面是更完整、可按自己的资料替换的版本。

1. 写作润色：这是我的周报原文：“这周需求梳理差不多，接口还没联调；周五再同步。”请改成清楚、简洁的进度说明。只依据原文，不增加进展、风险或责任人；不明确的完成项单列“待确认”。
2. 总结提炼：会议记录是：“周三交初稿；小李补数据；客户问上线进度。”请分为“明确待办”“待确认信息”“建议跟进”三类。不要把推导出的动作写成已经决定的待办，也不要猜交初稿的人。
3. 学习讲解：我刚开始学边际成本。请用“多做一个杯子”解释直观意思，再问我：“多做一个杯子需要的材料涨价，边际成本会怎样变化？为什么？”等我回答后，再指出可能的误解。
4. 分析拆解：活动报名下降。我目前只知道手上有近两周的曝光、点击和报名数据，但还没提供具体数字。请先说明应该计算哪些指标、如何定位变化环节，再列可能原因、验证方法及两种应对选项。不要把猜测写成结论。
5. 方案规划：我要做一页个人作品集，只有三个晚上，已有两个项目案例。请给出每晚的最小任务和一个可检查的交付成果；第 3 晚留出排版、校对和补缺口的时间。计划只是初稿，我会按实际进度修改。
